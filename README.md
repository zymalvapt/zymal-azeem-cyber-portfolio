# Zymal Azeem Cybersecurity Portfolio — Animated V2

Static HTML/CSS/JavaScript portfolio.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

If Node.js is installed:

```bash
npx serve . -l 5500
```

Then open `http://localhost:5500`.

## Main files
- `index.html` — page structure/content
- `styles.css` — design + animations
- `script.js` — interactive terminal, reveal animations, radar/card interactions, cursor effects
